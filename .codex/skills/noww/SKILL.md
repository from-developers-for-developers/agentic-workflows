# Work without ww

Do not use ww for the rest of this conversation, unless the user asks for it
again: do not run `./ww discover`, and do not start, continue, or complete a ww
task, `catchall` included. Carry out requests directly, as in a project without
ww. A ww task already in progress stays as it is; do not reset or fail it.
